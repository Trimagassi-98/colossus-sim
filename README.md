# Colossus Network Simulator

A high-performance C++ network simulator that models 
datacenter traffic routing, congestion detection, and 
dynamic rerouting - inspired by xAI's Colossus 
supercomputer network.

## Features (In Progress)
- Graph-based network topology
- Dijkstra shortest path routing
- ECMP load balancing
- Congestion detection and automatic rerouting
- Multithreaded traffic simulation
- Real-time performance metrics

## Tech Stack
- C++17
- CMake (build system)
- Google Test (testing)
